# Beatriz Barros — Site de divulgação

Site estático (HTML/CSS/JS), sem banco de dados.

## Antes de publicar
1. **WhatsApp:** edite `WHATSAPP_NUMBER` no topo de `script.js` (ex.: `5511999999999`).
2. **Fotos** em `assets/img/` (JPG, ideal 2400px no lado maior, até ~400 KB cada):
   `hero.jpg`, `beatriz-retrato.jpg`, `paris.jpg`, `lisboa.jpg`, `evento.jpg`, `hotel.jpg`, `desfile.jpg`, `og.jpg` (1200x630, preview ao compartilhar).
3. **Vídeos** em `assets/video/` (MP4 H.264, sem áudio, 5–10 s, 1080p, até ~6 MB):
   `hero.mp4` (fundo do topo) e `desfile.mp4` (faixa do meio).

Enquanto os arquivos não existem, o site mostra fundos dourados elegantes no lugar.

## Ver localmente
`python3 -m http.server 8000` e abra http://localhost:8000
